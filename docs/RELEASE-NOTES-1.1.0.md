# KIRIHARI 1.1.0（公開準備中）

新規プロジェクトの入力、フォルダでの素材登録、停止中のテロップと書き出し設定を改善しました。公開操作はまだ行っていません。

- 名前欄はグレーの入力例になり、そのまま入力できます。未入力でも既定名で開始できます。
- 素材欄へフォルダをドロップすると、子フォルダも含むMP4を登録します。大文字拡張子に対応し、重複登録を防ぎます。
- ポーズをまたぐテロップの両端を内側に寄せると停止位置で止まり、両端を揃えると停止時間中だけ表示します。
- 書き出しにオリジナル維持・学会スライド・YouTube FHD・詳細設定を追加。サイズ・fps・ビットレートを指定し、名前付き設定を10件保存できます。完成時間と予測容量も表示します。
- 詳しい使い方のPDFは12ページに更新。クイックスタートの内容は維持しています。

通常利用は `KIRIHARI-1.1.0-windows-x64.zip` をすべて展開し、KIRIHARI.exeを起動します。初回は不足部品を準備する画面へ進みます。AIに導入を依頼する場合はINSTALL.md、改編は対応ソースZIPとAI_EDITING.mdを参照します。

別添えはサンプルZIP、対応ソースZIP、3つのZIPを照合するSHA256SUMS.txtです。旧版のdataやoutputを上書きせず、新しいフォルダで使用してください。編集は素材込みのプロジェクトZIPで移行できます。

1.0のプロジェクトは1.1でも読めます。ポーズ専用テロップを含む保存だけは新形式になり、1.1以降が必要です。オリジナル維持も再エンコードであり、元データの完全コピーではありません。容量は内容によって変わる概算です。HDR、長時間素材、別PC・Windows 10の実機、未導入PCの.NET/WebView2実導入は未検証です。EXEはコード未署名です。

検証範囲はverification.md、配布条件はLICENSEとTHIRD-PARTY.mdを参照してください。
