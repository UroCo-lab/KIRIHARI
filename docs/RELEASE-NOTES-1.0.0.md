# KIRIHARI 1.0.0

**動画を切って、説明を貼る。** Windows向けのポータブル動画編集アプリです。

残したい範囲のドラッグ指定、複数動画の配置、テキスト・図形・画像の重ね合わせ、ポーズ、プロキシ編集、H.264 / MP4書き出し、素材を含むプロジェクトZIPに対応します。

サンプル関連のボタンを整理し、動画は別添えの任意ダウンロードにしました。

Undo/Redo、保存状態の表示、異常終了時の自動保存復元、カット範囲の秒数入力、書き出した動画・保存先を開く操作も備えています。

## ダウンロードするファイル

- **KIRIHARI-1.0.0-windows-x64.zip**：通常はこちら。本体と使い方を収録。
- **KIRIHARI-1.0.0-samples.zip**：練習用のサンプル動画。任意。
- **KIRIHARI-1.0.0-source.zip**：この版のソースとビルド手順。開発者向け。
- **SHA256SUMS.txt**：上記3ファイルのSHA-256。

## 起動まで

1. 本体ZIPをすべて展開し、書き込み可能なフォルダに置きます。
2. `KIRIHARI.exe` を起動し、初回の **はじめの準備 → 必要な部品を準備** を押します。FFmpegの取得・配置は自動です。.NET FrameworkやWebView2が必要な場合はMicrosoftのインストール画面へ進みます。
3. **KIRIHARIを始める** を押し、新規プロジェクトから素材を読み込みます。次回から準備画面は省略します。

Windows 10/11 x64、.NET Framework 4.8以降、WebView2 Evergreen Runtimeが必要です。本体同梱の `docs/KIRIHARI-クイックスタート.pdf` に起動から簡単な編集・保存までを2ページでまとめています。初回準備のみの `docs/KIRIHARI-はじめかた.pdf`、詳細な `docs/SETUP.md` も収録しています。本版はコード未署名です。

「設定」「使い方」または起動画面から、クイックスタートと「詳しい使い方」（印刷用PDF・10ページ）を開けます。AIへ導入を依頼するときは `INSTALL.md` と `install.ps1`、好みに合わせて改編するときは対応ソースZIPと `AI_EDITING.md` を使用してください。インストールスクリプトは既存の導入先を上書きしません。

## 制限と検証範囲

再生速度の変更は確認用です。区間ごとの速度変更、単色画面の挿入は現行版の書き出しに対応しません。可変フレームレート素材の厳密なフレーム一致、HDR、長時間素材の性能、別PCやWindows 10での実機動作は未検証です。ローカルで行った検証は `docs/verification.md` に記録しています。
