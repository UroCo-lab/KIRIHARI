# KIRIHARI 1.2.0（公開準備中）

- カットの端をダブルクリック、または右クリックの「開始・終了時刻を指定」から、オリジナルのタイムライン時刻で範囲を設定できます。時・分・秒・ミリ秒の直接入力、上下ボタンと上下キーに対応します。
- 例：「1時間3分15.4秒〜1時間3分17.5秒」は、開始を1時3分15秒400ミリ秒、終了を1時3分17秒500ミリ秒に指定します。完成動画に残す範囲です。入力は素材のフレーム単位に丸め、ポーズ時間は加算しません。
- テロップの「遷移」で、入る時間と出る時間をそれぞれ0.01〜60秒で指定できます。プラス・マイナスボタンは0.1秒ずつ調整します。短い表示区間では比率を保って短縮し、実際の時間を表示します。

既存プロジェクトと、従来の共通の遷移時間設定を読み込めます。個別の遷移時間の編集には1.2以降を使用してください。元動画・既存プロジェクトを残し、新しいフォルダで利用します。公開はまだ行っていません。

通常利用は本体ZIP、改編には対応ソースZIPを使用します。初回導入はINSTALL.md、操作は同梱PDF、検証範囲はverification.mdを参照してください。
