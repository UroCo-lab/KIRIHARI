# KIRIHARI 1.8.5（公開準備中）

- 速度に16倍と32倍を追加しました。32倍は映像を間引く無音のプレビューです。
- 再生中は ↑／↓ で速度を変え、←／→ で戻る・進むことができます。大きい送り幅は再生範囲の約1%です。5時間の元動画では3分です。
- 設定の「送り戻しの幅」で、小ボタンと大ボタン・ホットキーそれぞれの割合と最低秒数を変更できます。
- 設定の「ホットキー」で割り当てを変更できます。再生／一時停止、テロップ挿入、ここから残す、分割、ポーズ追加も割り当てられます。
- 「元に戻す」「やり直す」はタイムライン上のボタンとキーボード操作から使えます。
- 長時間・大容量素材へのプロキシ案内と、読み込み完了後に編修後プレビューを開始する修正も含みます。
