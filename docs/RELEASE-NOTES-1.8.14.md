# KIRIHARI 1.8.14（公開準備中）

- 編集ファイルと素材込みZIPを別々に保存できます。ZIPの保存前に、収録する素材名・使用状況・合計容量を確認できます。保存と読み込みには進捗と中止ボタンがあります。
- ZIPを開く前に必要な素材と空き容量を確認します。失敗や中止で残った展開途中の素材は削除します。
- 元動画が見つからない場合は、保存時の内容照合情報を使って選び直した素材を確認します。照合情報がない編集ファイルでは、候補の映像・長さ・解像度を確認してから開きます。
- カットなどの追加と編集ファイルの読み込みで、同じ件数上限を適用します。
- 「一部分を除く」の確認画面に完成尺の前後とテロップへの影響を表示します。
- カット一覧で全角の数字や時刻、分・秒での表記、素材名と倍率の組み合わせを検索できます。絞り込んだ件数を表示します。

導入と必要環境は [SETUP.md](SETUP.md)、対応ソースの使い方は [AI_EDITING.md](../AI_EDITING.md) を参照してください。
