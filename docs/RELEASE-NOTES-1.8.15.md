# KIRIHARI 1.8.15（公開準備中）

KIRIHARIは無償で利用でき、自分のPCや作業に合わせて自由に改変できるWindows向け動画編集ソフトです。本体と同じ版のソースを用意しているので、普段使っているAIに調整を頼めます。

## ダウンロードと起動

1. Assetsから **KIRIHARI-1.8.15-windows-x64.zip** と **SHA256SUMS.txt** をダウンロードします。PowerShellで `Get-FileHash -Algorithm SHA256 -LiteralPath .\KIRIHARI-1.8.15-windows-x64.zip` を実行し、ZIPのSHA-256を記載値と照合します。
2. 本体ZIPを **すべて展開** し、書き込み可能で階層の浅いローカルフォルダで **KIRIHARI.exe** を開きます。初回は **必要な部品を準備** を押し、完了後に **KIRIHARIを始める** を押します。
3. **練習動画で試す** を押すと、同梱の猫の動画を編集できます。

展開から最初のMP4書き出しまでを、同梱の **クイックスタート（PDF）** で確認できます。機能ごとの操作は **詳しい使い方（PDF）** を参照してください。

本体はWindows x64向けです。Windows 11 x64で動作を確認しました。Windows 10、Windows on ARM、依存部品が未導入の別PCでの初回セットアップは未検証です。EXEは未署名のため、SmartScreenなどが警告を表示することがあります。

**KIRIHARI-1.8.15-samples.zip** は追加の練習素材、**KIRIHARI-1.8.15-source.zip** とGitHubの **Source code** は開発用です。

## AIに改変を頼む

本体と同じ版の **KIRIHARI-1.8.15-source.zip** を展開します。展開したソースと同梱の `AI_HANDOFF.md` をAIに渡し、画面や操作など、自分の環境に合わせて変えたいことを伝えてください。

## 主な変更

- 狭い画面では「速度」「縮尺」の倍率付きボタンにマウスを置くか押すとスライダーが開きます。「設定」は用途ごとの5つのグループに分かれています。

- タイムラインの縮尺を1〜100倍で連続調整できます。時間目盛りの上のゲージが、全体のうち表示中の範囲を示します。「一部分を除く」はカット行に、「文字を入れる」は「テロップ」の隣にあります。

- Windows 11では、編集ウィンドウのタイトルバーもテーマと同じ配色になります。
- 画質選択画面の「プロキシとは」で、倍速再生や場面移動の利点と、長い動画では作成に時間がかかることを案内します。
- 画質選択のボタンに、高画質のH、最軽量のL、バランス型のM（推奨）の選び分けを表示します。

- プレビューに H（720p）、M（480p・推奨）、L（360p）、ORIGINAL（元動画）を追加しました。
- 重い素材を読み込んだときにオリジナル・H・L・Mを選べます。編集する動画を選ぶ画面でも素材名の左のボタンから選べます。
- プロキシの変換中は、素材を選ぶ画面と編集中の画面上部で、進捗と自動切り替えの案内を確認できます。
- カットの開始・終了時刻を逆に入力した場合も、早い時刻から遅い時刻までをカット範囲にできます。
- カット時刻の入力欄は、TabとShift＋Tabで前後に移動できます。
- 「プロキシ管理」から画質別に作成・再生成・中止・削除ができ、素材ごとの容量とキャッシュの合計容量を確認できます。
- プロキシの作成中も編集を続けられます。作り直すときは、新しいプロキシを検証してから旧コピーを置き換えます。
- プロキシは元動画のフレームの表示時刻を維持します。MP4書き出しと素材込みZIPは元動画を使います。
- デコーダーで補える破損があっても生成を続けます。元動画との時刻照合を通ったコピーを使います。
