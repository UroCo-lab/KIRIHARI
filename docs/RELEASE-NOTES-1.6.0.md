# KIRIHARI 1.6.0（公開準備中）

- カット行の空欄に、ドラッグして残す範囲を選ぶ案内を表示します。
- 新規編集では元の音声がMP4に入ります。書き出し画面で音声の有無を選べます。プレビューのミュートは独立しています。旧プロジェクトは従来の書き出し設定を引き継ぎます。
- 起動画面から猫の練習動画を開けます。新規プロジェクトに動画を1本読み込むと、自動でメイン動画に選ばれます。
- 最初のテロップは「文字を入れる」から直接入力できます。
- 編集画面に「編集を保存」と「MP4を書き出す」を並べました。完了後は「完成動画を見る」から確認できます。ZIP保存と作業フォルダの操作は折りたたみにまとめました。
