# KIRIHARI 1.3.0（公開準備中）

- ポーズの円をダブルクリック、または右クリックの「ポーズの位置を変更」で、オリジナルの時・分・秒・ミリ秒による位置指定ができます。ドラッグでも同じカット内を移動できます。同じ位置のポーズには重ねられません。
- 停止中だけ表示するテロップは、ポーズを移動すると追従します。移動は元に戻す・やり直す、保存・再読込に対応します。
- 図形を選択し、上の丸いハンドルで回転できます。Shiftを押すと15度刻み。「角度」と「回転・反転」では角度入力、左右90度回転、左右・上下反転ができます。吹き出しの黄色いハンドルは突起の先端です。
- 新しいアイコンをEXE・初回準備・編集画面に組み込みました。詳細PDFも同梱しています。

回転・反転の再編集には1.3以降を使用してください。古いアプリは新しい図形の向きを反映できません。既存の元動画・プロジェクトは残し、新しいフォルダへ展開してください。公開操作は行っていません。
