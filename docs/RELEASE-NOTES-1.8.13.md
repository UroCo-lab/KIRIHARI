# KIRIHARI 1.8.13（公開準備中）

- 未保存の編集から別の編集へ切り替えるときに、その場で保存、破棄、キャンセルを選べます。
- 元動画が見つからないときは、元と同じファイルを選び直して編集を開けます。「設定」から、素材を含むプロジェクトZIPを保存できます。
- ドラッグで残す範囲を選ぶと、Kで選ぶ場合と同じように既存カットの間を埋めます。「一部分を除く」は複数の帯に使え、テロップや静止への影響を確認してから適用できます。
- 元動画の再生中はKの案内を表示します。しおりや使い方を開いても記録中の範囲を保持します。プレビュー速度と完成動画のカット倍率を表示名で区別します。
- カット一覧から、時刻・素材名・倍率で絞り込み、目的のカットに移動・拡大できます。
