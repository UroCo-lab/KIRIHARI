# KIRIHARI 1.8.8（公開準備中）

- 「元動画」を再生中に **K** を押すと、完成動画に残す範囲の記録を始めます。再生位置に合わせて仮の帯が伸び、もう一度 **K** を押すと確定します。そのまま再生が続きます。記録中は **Esc** で取り消せます。
- タイムラインの **しおり** から、元動画の現在位置にメモを残せます。一覧の時刻を押すと、その場面に戻れます。
- カット帯を右クリックして **このカットを拡大** を選ぶと、カットの両端が見える縮尺に切り替わります。 **全体表示** でタイムライン全体に戻せます。
- しおりを含むプロジェクトは1.8.8以降で開けます。既存のプロジェクトも引き続き開けます。
