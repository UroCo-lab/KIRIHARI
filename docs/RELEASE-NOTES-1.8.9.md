# KIRIHARI 1.8.9（公開準備中）

- 起動画面の入口を「動画を選んで編集」と「前の編集を開く」に整理しました。練習動画へのボタンは初回起動時に表示します。次回以降は起動画面の「メニュー」や編集中の「設定」から開けます。
- プレビューに「元動画を表示中」「編修後を表示中」を表示します。完成動画内で映像を止める操作を「静止を追加」に変更しました。
- 長時間や高画質の動画を取り込む際は、再生や場面探しを軽くする編集用コピーとして案内します。
- 「完成動画を作る（MP4）」では完成尺・音声・保存先を先に確認できます。学会スライド向けなどの用途から画質を選び、サイズやフレームレートは「出力仕様」で確認できます。
