# KIRIHARI サンプル動画

この表の素材は別添えZIPで入手できます。本体には `samples/lightweight` に猫の12秒版、差し込み、光学ステージ、通常画面用の編集見本が入っています。ZIPを展開し、KIRIHARIの **新規プロジェクト → 素材を開く** からMP4を選んでください。本体の隣へ配置する必要はありません。

| ファイル | 内容 |
| --- | --- |
| cat-motion.mp4 | 3分の猫のアニメーション。メイン素材の練習用。 |
| insert-motion.mp4 | 7秒のロケット。差し込み素材の練習用。 |
| optical-motion.mp4 | 2秒の光学ステージ。短い動作確認用。 |

猫をメインに選び、ロケットを素材に追加すると、メディアプールからオリジナル行の先頭・末尾やカット行へドラッグして試せます。

テロップの **画像** から `samples/lightweight/images` にある `transparent-badge.png` と `color-card.jpg` を挿入できます。透過PNGは背景が透け、JPEGは画像全体に色が付いています。透過度を変えて違いを試せます。画像は `make-test-images.py` で再生成できます。

これらはKIRIHARI用に作成した架空の素材で、MIT Licenseで利用・改変・再配布できます。再配布するときは著作権表示と許諾文を添えてください。 [LICENSE](../LICENSE)

ソース配布には、猫の生成スクリプト（PythonとPillowを使用）と旧UI用の参照画像・編集見本も含みます。`光学ステージ_編集見本.kirihari` は旧UI形式で、通常の動画編集画面用ではありません。
