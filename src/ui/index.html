KIRIHARI クイックガイド
  1. 動画を開く　新規プロジェクトで素材を読み込みます。1本なら自動で選択されます。起動画面の「練習動画で試す」から、同梱の猫の動画も開けます。
  2. 残す場面を選ぶ　赤いつまみで場面を探し、カット行をドラッグします。元動画の再生中はKで範囲を記録し、もう一度Kで確定できます（初期設定）。途中だけ外すときは「一部分を除く」を使います。「しおり」から、あとで戻りたい場面にメモを付けられます。
  3. 別の動画を差し込む　「動画情報・素材」のメディアプールからカット行にドラッグします。帯はドラッグで移動でき、両端を調整するときは右クリックから「カット」を開きます。赤い帯は重なりを示します。
  4. テロップを重ねる　白いカット帯ができたら「文字を入れる」を押して直接入力できます。追加した行は自動で広がります。「挿入」で空のスライドを作ることもできます。
  5. 保存と書き出し　「編修後」で残す範囲を続けて再生できます。「編集を保存」で後から編集を再開し、「完成動画を作る（MP4）」で共有できる動画を作ります。

縮尺は1〜100倍で調整できます。狭い画面では「速度」「縮尺」にマウスを置くか、押すとスライダーが開きます。拡大中は目盛り上のゲージで表示範囲を確認できます。仕切りを上下にドラッグすると、プレビューとタイムラインの高さを調整できます。
